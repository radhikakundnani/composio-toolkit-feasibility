            Live page: radhikakundnani.github.io/composio-toolkit-feasibility/ · Code and data: github.com/radhikakundnani/composio-toolkit-feasibility

            Needs Python 3.10+ and a Composio API key with write scope on sessions. Extraction and verification are prompt files that any agent runner can execute; this run used Claude subagents.

            
  
            Machine-readable output: results.json has every record, evidence URL, cross-check, change log and score, so an agent can use it directly.
